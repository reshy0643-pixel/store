# Ad copywriting & TikTok strategy

## Hook (first 1–2 s decides everything)
Formulas (write 5, pick the best):
- Question: "تبين ريحتك تثبت طول اليوم؟" / "Want a scent that lasts all day?"
- Bold claim: "هذا العطر خلّى الكل يسألني عنه"
- POV: "POV: لقيت عطر شبيه بالـ…بنص السعر"
- Contrast: "عطرك يروح بعد ساعة؟ جرّب هذا"
- Number/list: "3 عطور تخليك مميز في الشتاء"
- Visual-first: product + action in frame 1 (spray, splash) with 3–6-word overlay.

## Script structures (15–30 s)
- **PAS:** Problem → Agitate → Solution (product) → CTA.
- **AIDA:** Attention → Interest (notes, ingredients) → Desire (feeling, compliments) → Action.
- **Demo:** hook → show texture/spray/longevity → result → offer.
Sell the **feeling** (confidence, compliments, occasions), then the facts (notes, longevity, size, price).

## Formats that work for perfume/beauty
Unboxing ASMR, "smells like…" (dupe), scent layering, perfume for every occasion, before/after (makeup), GRWM, "rate my collection", customer reaction/UGC, gift ideas (Eid, Ramadan, Valentine, Mother's Day, National Day). Trends change weekly — check TikTok Creative Center before using a sound/trend; don't invent "current" trends.

## Copy rules
- Arabic: short, warm, conversational; match dialect to audience; avoid stiff MSA in captions.
- English: rewrite, don't translate; same beats.
- Specific > generic ("يثبت 12 ساعة" beats "ثابت جداً") — only claims the user can back up.
- One CTA: "اطلب الآن — الرابط في البايو" / "Order now — link in bio"; urgency only when real (limited stock, offer ends).
- Respect platform rules: no false health claims, no fake reviews or fake scarcity.

## Post caption & hashtags
Caption: hook line + 1 benefit + CTA + 3–5 hashtags (mix: 1–2 broad `#عطور #perfume`, 2 niche `#عطور_نسائية #عود`, 1 location `#الرياض`). Emojis sparingly (✨🌹).

## Posting
1–2 posts/day while testing; test 3 hooks on the same video; keep what holds viewers past 3 s; repost winners with new hooks. Peak times vary — use TikTok analytics for the account's audience.
